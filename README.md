# Работа Бандита — обновлённая версия

## Что добавлено

- Рассылка по **чатам, где находится бот**.
- Два режима рассылки: обычная и **РЕКЛАМА**.
- Рассылка поддерживает текст, фото, видео и кружочки: отправляется следующее сообщение администратора через `copyMessage`.
- `/чаты` — список активных чатов. Видит только администратор.
- Отдельная статистика по каждому чату и топ активных пользователей.
- Лог активности пользователей по сообщениям.
- VIP-задания с прогрессом.
- Ручная выдача VIP: `/выдатьVIP ID УРОВЕНЬ СРОК`.
- Снятие VIP: `/снятьVIP ID`.
- VIP на 7/30/90 дней или навсегда (`0`).
- Активные розыгрыши в разделе **«📜 События»** вместо истории транзакций.
- Админские логи.
- Общая информация для новичков, которую админ может менять.
- **Профиль → Мои бизнесы → Свой магазин** уже реализовано через кнопку `🏪 Мой магазин` внутри магазина; существующие данные магазина сохраняются.
- Исправлен вывод `\n` в VIP и других сообщениях: теперь это настоящие переносы строк.

## ВАЖНО: база данных

Обновление использует `CREATE TABLE IF NOT EXISTS` и мягкие `ALTER TABLE` миграции. Существующие пользователи, деньги, Респекты, VIP, инвентарь, магазины, казино и история не удаляются.

**Перед обновлением всё равно сделай резервную копию `bot.sqlite`.**

## Команды администратора

### Основные

- `/safonof` или `/admin` — открыть админ-панель.
- `/помощьадмин` — краткая инструкция.
- `/чаты` — список чатов бота.
- `/статистика` — общая статистика + выбор конкретного чата.

### Деньги

- `/give ID СУММА` — выдать деньги.
- `/take ID СУММА` — забрать деньги.
- `/setmoney ID СУММА` — установить баланс.
- `/safonof51 ID СУММА` — выдать Респекты.

### Администраторы

Только главный администратор:

- `/safonof50 ID` — добавить администратора.
- `/safonof50 ID del` — удалить администратора.

### VIP

- `/выдатьVIP ID УРОВЕНЬ СРОК`
- Уровень: `1`–`5`.
- Срок: `7`, `30`, `90` или `0` (навсегда).
- `/снятьVIP ID` — снять VIP.

Пример:

`/выдатьVIP 123456789 5 30`

### VIP-задания

Команда:

`/viptask Название | тип | количество | деньги | респекты | VIP`

Типы:

- `work` — работы.
- `robbery` — ограбления.
- `chat` — сообщения в чате.

Задания, которые предусмотрены сейчас:

- 🎯 5 работ → 4 500 бабок.
- 🔪 3 ограбления → 10 000 бабок.
- 💬 30 сообщений → 15 000 бабок + 10 Респектов.

Их можно создать командой:

`/viptask 5 работ | work | 5 | 4500 | 0 | 1`

`/viptask 3 ограбления | robbery | 3 | 10000 | 0 | 1`

`/viptask 30 сообщений | chat | 30 | 15000 | 10 | 1`

### Рассылки

- `/рассылка` — запустить обычную рассылку.
- `/реклама` — запустить рекламную рассылку.
- `/отмена` — отменить ожидание сообщения.

После команды просто отправь **следующим сообщением** текст, фото, видео или кружочек.

### События

Создание:

`/event Название | описание | деньги | респекты | победители | часы`

Пример:

`/event Розыгрыш 10000 | Участвуй в розыгрыше | 10000 | 0 | 3 | 24`

Удалить/завершить:

- `/event_del ID`
- `/event_end ID`

Пользователям показываются только активные будущие события.

### Новички

Изменить общий текст:

`/новичкам НОВЫЙ ТЕКСТ`

Посмотреть пользователям:

`👋 Новичкам`

## Как включить учёт активности в группах

Чтобы Telegram отправлял боту обычные сообщения из групп:

1. Открой `@BotFather`.
2. Выбери бота.
3. Открой **Bot Settings → Group Privacy**.
4. Нажми **Turn off**.
5. Добавь бота в нужные группы.

Бот будет считать сообщения пользователей. Сообщения самого бота не учитываются.

## Railway

1. Укажи токен и ID главного администратора в `config.php`.
2. Используй persistent Volume для SQLite.
3. Для сохранения базы укажи `DB_PATH`, например `/data/bot.sqlite`.
4. После деплоя установи webhook Telegram на публичный адрес приложения.
5. Проверь `/start`, `/safonof` и `/чаты`.

## Важно про токен

Токен бота был обнаружен в исходном `config.php`, который был загружен в чат. После публикации/передачи файла безопаснее **перевыпустить токен через BotFather** и заменить его в `config.php`.
