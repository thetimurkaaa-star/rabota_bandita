# Работа бандита — новая версия

## Файлы

- `index.php` — основной Telegram-бот.
- `config.php` — токен и главный администратор.
- `schema.sql` — структура SQLite.
- `README.md` — установка.

## Установка

1. Создай Telegram-бота через BotFather.
2. В `config.php` укажи `BOT_TOKEN`.
3. Укажи настоящий Telegram ID главного администратора в `MAIN_ADMIN_ID`.
4. Загрузи файлы на Railway.
5. В Railway добавь persistent Volume и направь `DB_PATH` на файл внутри Volume, например `/data/bot.sqlite`.
6. Настрой webhook Telegram на публичный URL приложения.

## Команды

- `/start`
- `/ставка 10000`
- `/safonof` — админ-панель.
- `/safonof52 текст` — рассылка для администрации.
- `/give ID SUM`
- `/take ID SUM`
- `/setmoney ID SUM`

## Важно

В этой сборке базовая игровая система и SQLite уже подготовлены. Механика `/ограбить ID` и полноценный пошаговый сценарий защиты жертвы оружием лучше дописать отдельным модулем состояния диалогов, чтобы callback-кнопки и кулдауны не конфликтовали с другими играми.
