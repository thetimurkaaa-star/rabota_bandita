# Работа Бандита — Railway + PostgreSQL

Готовая версия Telegram-бота на **PHP 8.3 + PostgreSQL** для Railway. Python, Node.js и npm для работы бота не нужны.

## Что внутри

- 💰 Бабки — основная игровая валюта.
- 💼 Работа и ежедневный 🎁 бонус.
- 👤 Профиль, `/balance`, `/top`.
- 🚨 Ограбление игроков с учётом силы, оружия, брони и VIP.
- 🏪 Свой магазин: накопление дохода, улучшения и ограбления другими игроками. Один конкретный магазин можно грабить не чаще 1 раза в 3 дня.
- 🔪 Нож, 🔫 пистолет, 🔫 автомат, 🛡 броня.
- 💪 Прокачка силы до 100.
- 🎰 Казино: слоты, кубик, высокая карта; ставка вводится своей суммой через `/ставка СУММА`.
- 💎 VIP 1–5, Респекты, временная/вечная выдача администратором.
- 🎯 VIP-задания.
- 🎉 События и розыгрыши.
- 🏆 ТОП по балансу.
- 👑 Админ-система: экономика, VIP, задания, рассылки, чаты, статистика, события, логи, добавление/удаление администраторов.
- 👥 Счётчик пользователей бота в общей статистике.
- 🏠 Автоматическое сохранение подключённых групп/супергрупп/каналов для рассылок и статистики.

## Railway

1. Создай проект в Railway.
2. Добавь PostgreSQL через **Add → Database → PostgreSQL**.
3. Добавь сервис бота из этого проекта/GitHub. Railway использует `Dockerfile` автоматически.
4. В Variables бота добавь:
   - `BOT_TOKEN` — токен из BotFather.
5. `DATABASE_URL` должен быть доступен сервису бота от подключённой PostgreSQL. На Railway он обычно подставляется автоматически после подключения базы.
6. Нажми Deploy.

**Никакую базу вручную создавать не надо.** При первом запуске `schema.sql` создаёт таблицы автоматически.

## Главный администратор

В `config.php` указан `MAIN_ADMIN_ID`. Если это твой Telegram ID, после `/start` бот автоматически выдаст ему статус главного администратора.

Команды главного администратора:
- `/safonof` — админ-панель.
- `/safonof50 ID` — добавить администратора.
- `/safonof50 ID del` — удалить администратора.
- `/safonof51 ID СУММА` — выдать Респекты.

Обычные администраторы используют `/give`, `/take`, `/setmoney`, `/выдатьVIP`, `/снятьVIP` и функции панели.

## Важно

Токен бота не хранится в коде — он берётся из Railway Variables. Если старый токен уже публиковался, его лучше перевыпустить через BotFather.
