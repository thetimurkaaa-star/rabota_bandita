# 💰 Работа Бандита — Telegram Bot

Готовый PHP + SQLite Telegram-бот с валютой **💰 Бабки**.

## Возможности
- 💰 профиль и баланс
- 💼 работа
- 🎁 ежедневный бонус
- 🔫 ограбление
- 🏪 магазин-заготовка
- 🎰 казино
- 👑 админ-команды `/give` и `/take`
- 💾 SQLite
- 🚀 Railway
- ❌ без Python
- ❌ без Node.js

## 1. Создай бота
В Telegram открой @BotFather, создай бота через `/newbot` и скопируй токен.

## 2. Узнай свой Telegram ID
Напиши боту @userinfobot или используй любой способ узнать свой ID.

## 3. Railway
Создай новый проект в Railway и загрузи этот репозиторий/папку.

В Variables добавь:

BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
ADMIN_ID=ТВОЙ_TELEGRAM_ID

Railway запустит:
`php -S 0.0.0.0:$PORT index.php`

## 4. Важно про SQLite
SQLite хранится внутри контейнера. Для первого запуска и тестирования этого достаточно. Для постоянного продакшена лучше подключить Railway Volume, смонтированный в `/app/data`, чтобы база не исчезала при пересоздании контейнера.

## 5. Команды
/start
/balance
/profile
/work
/bonus

Администратору:
/give USER_ID AMOUNT
/take USER_ID AMOUNT

Пример:
/give 123456789 1000000

## Валюта
Везде используется только:
💰 Бабки

Примеры:
💰 5.000 бабок
💰 125.500 бабок
💰 1.000.000 бабок
